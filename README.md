**追踪 · 调研 · 展示人工智能领域相关法规信息。**

以「智能 / 大模型 / 算力 / 数字化」等主题词为线索，持续收录人工智能领域的中央法规、地方法规、立法资料、法规解读与法律动态，融合为一份按标题去重的统一数据集，并通过网页与 RSS 对外展示。

## 亮点

- **持续追踪**：每日定时巡检最新法规动态，延迟入库的条目定期复核补全，历史数据可追溯至 2010 年。
- **统一数据集**：双渠道收录、按标题去重融合，沉淀为一份结构化 CSV，字段涵盖类别、标题、链接、公布/施行日期、制定机关、效力位阶、时效性、发文字号与主题标签。
- **网页浏览**：开箱即用的静态页面，支持按分类、效力位阶、制定机关与关键词组合筛选。
- **RSS 订阅**：自动生成 RSS 2.0 订阅源，新法规第一时间送达你的阅读器。
